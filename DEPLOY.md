# Deploy in 5 minutes (GitHub Pages, free)

1. Sign in at github.com and click **New repository**. Name it `clinic-triage`, set it to **Public**, click Create.
2. Click **uploading an existing file**, drag in everything from this folder (including `index.html`), click **Commit changes**.
3. Go to **Settings > Pages**. Under Source choose **Deploy from a branch**, branch **main**, folder **/ (root)**, then Save.
4. Wait 1-2 minutes. Your live link is `https://YOUR-USERNAME.github.io/clinic-triage/`.
5. Open it in a private/incognito window to confirm it works without logging in.
6. Edit `README.md` and replace `[PASTE YOUR GITHUB PAGES LINK HERE]` with that link.

Never commit an API key. The app asks visitors to paste their own.
